1. 账号与资源隔离

两个选题可以使用同一组个人账号。分别建项目目录、仓库和 Azure 资源组，使用不同前缀，便于说明和检查。不要把不同学生的个人提交身份或运行证据混在一起。

模板默认 Translator F0；若同一订阅已有免费 Translator 资源，第二次创建可能失败。届时选择复用已有资源并填写 Function 设置，或在了解费用后选择 S1。脚本不会自动切换付费层。

2. 建资源

以后安装 Azure CLI、登录并选定真实订阅，检查 infra/main.json 的资源和费用。下面名称为示例，部署前替换为自己确认的资源组与区域。

az login
az account set --subscription <真实订阅ID>
powershell -File scripts/Deploy-Resources.ps1 -ResourceGroup stayatlas-coursework -Location <区域>
# 首次资源组不存在时，先审阅模板，再执行：
powershell -File scripts/Deploy-Resources.ps1 -ResourceGroup stayatlas-coursework -Location <区域> -Apply

资源包括 Storage、私有 assets Blob、Cosmos DB for NoSQL 的 stayatlas/assets（分区键 /id）、Node.js 22 Linux Flex Consumption（FC1）Function 及 Translator。模板按增量模式部署，继续使用同名的 Storage、Cosmos DB 和 Translator。静态网站通过后续发布脚本启用。

3. 授权两个 API connection，创建工作流

在 Azure Portal 为 Blob Storage 和 Cosmos DB for NoSQL 建立并授权 managed API connections。Cosmos 的 MongoDB API 不适用于本工作流。确认连接类型和目标资源后运行：

powershell -File scripts/Configure-Workflows.ps1 -BlobConnectionName <Blob连接名> -CosmosConnectionName <Cosmos连接名>
# 读取并审阅 .local/cloud/workflows.generated.json，验证后：
powershell -File scripts/Configure-Workflows.ps1 -BlobConnectionName <Blob连接名> -CosmosConnectionName <Cosmos连接名> -Apply

生成器会获取该区域实际 connector Swagger，根据 operationId 创建 IUPS/RAI/RIPS/UIPS/DIPS/FIPS 六个工作流，不猜测连接器路径。实际云端仍需验证权限、参数、回调和执行结果。Blob 与数据库操作不具备跨服务事务，失败运行需核查孤立文件。

4. 打包、配置 Function、发布静态站点

npm ci
npm run check
npm test
npm run build
powershell -File scripts/Package.ps1
powershell -File scripts/Publish-Application.ps1 -FunctionZip ../output/airbnb/StayAtlas_Function.zip
# 审核预览中的目标后，再加 -Apply 执行

Function 包带 data/，用来验证上传关联的房源。静态输出同样包含只读索引和逐房源评论。Function 用管理口令保护写入，六个签名回调、Translator 密钥和口令都只保存在云端设置及忽略的本地私密目录，不能放到前端或 PPT。

发布脚本把真实 API 地址写入 dist/config.js 的 STAYATLAS_CONFIG.apiBase。ALLOWED_ORIGINS 只填实际网站 origin。请检查 PDF.js 的 mjs / wasm 文件类型和跨域预览。更换 API 后重新构建发布。

5. GitHub 到 Azure DevOps 的真实 build

把本项目作为独立 GitHub 仓库上传，再在自己的 Azure DevOps 项目建立 Pipeline 并选择根目录 azure-pipelines.yml。它使用 Node 22、npm ci、语法检查和 JUnit 测试，并构建静态网站。保存一次真正成功的 run 页面、测试结果和 frontend artifact。YAML 文件本身不能证明实际 build 成功。自动发布属于可选扩展。

6. 验证并录制

# PowerShell，值仅在本终端使用：
$env:STAYATLAS_BASE_URL='https://<真实Function域名>'
$env:STAYATLAS_WRITE_TOKEN='<从本地私密记录读取的口令>'
node scripts/smoke.cjs

smoke 只创建、更新和删除自己的临时测试资料；在 HTTPS 云端会要求真正配置并调用 Translator。还需到 Portal 检查 Blob/Cosmos 删除、六个工作流运行记录、Function 和 Pipeline。记录 URI 时遮盖 sig、key、token 等凭据。

按 CW2 视频脚本，由本人录制 ≤5 分钟的演示，尽量出镜。当前只准备脚本，没有虚构个人录屏或云端证据。
